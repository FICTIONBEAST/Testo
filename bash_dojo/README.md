# Bash Dojo 🥋

An interactive, Socratic-style bash learning system. Learn by doing, not by reading.

## How It Works

1. Run `./start.sh` to begin
2. Complete missions that teach you real bash skills
3. Each mission builds on the previous one
4. Hints are available if you get stuck

## Getting Started

```bash
cd bash_dojo
chmod +x start.sh
./start.sh
```

## Mission Categories

- **File Ninja**: Navigation, creation, manipulation
- **Text Samurai**: grep, sed, awk, pipes
- **Process Sensei**: ps, jobs, background tasks
- **Permission Master**: chmod, chown, users

Good luck, grasshopper.
